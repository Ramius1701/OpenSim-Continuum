Simulator configuration belongs to the host running this region. Use its native RegionWeb control room to edit allowed region definitions, save with backups and apply supported reloads. Name, location, port and size changes may require a simulator restart and registry refresh.

{IfRegionEditorControlRoomBegin} Open configured simulator control room

The control room verifies its own estate-owner login. Portal sessions and privileges are not forwarded. Select this region's definition in the host's Region definitions list.

{IfRegionEditorControlRoomEnd} {IfRegionEditorNoControlRoomBegin}

No simulator control room is configured for this region. The grid operator can add its HTTPS URL under ContinuumWebUIRegionControlRooms and enable RegionWeb on the host.

{IfRegionEditorEstateEnd} {IfRegionEditorConsoleBegin}

Open native host consoles for operator commands, provisioning and restarts. Choose the host matching this region and authenticate with its console credentials.

{IfRegionEditorConsoleEnd}

Changes are confirmed by the native control room or console. Opening this page does not save, reload, create or delete a region. A single shared login across simulator hosts is not implemented.
